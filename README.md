# ConsolaBasica

Descripción
-----------

Proyecto de consola en C# que sirve como plantilla básica y de aprendizaje. Está dirigido a .NET 8 y contiene la estructura mínima para iniciar una aplicación de consola, incluyendo ejemplos de entrada/salida y configuración del proyecto.

Características
---------------

- Proyecto de consola en .NET 8
- Estructura limpia y fácilmente extensible
- Ejemplos de uso básico de entrada y salida en consola

Requisitos
---------

- .NET 8 SDK
- Visual Studio 2022/2026 o VS Code (con C#)

Cómo ejecutar
-------------

1. Restaurar paquetes (si procede):

   dotnet restore

2. Compilar:

   dotnet build

3. Ejecutar:

   dotnet run --project ./Ruta/Al/Proyecto

Nota: desde Visual Studio abre la solución `ConsolaBasica.slnx` y ejecuta normalmente.

Ejemplo de uso
--------------

Al ejecutar la aplicación, la consola puede pedir datos al usuario y mostrar resultados básicos. Modifica el punto de entrada Program.cs para personalizar la lógica según tus necesidades.
